# 🎓 TeachMate AI

## Personalized AI Teaching Assistant

TeachMate AI is an AI-powered personalized teaching assistant designed to adapt learning content according to a student's learning level, preferred language, and learning style.

The application uses Generative AI to create personalized lessons, answer student questions, evaluate understanding, and generate quizzes.



## 🚀 Features

### 1. Personalized Learning
Students can provide:
- Student name
- Learning level
- Preferred language
- Learning style
- Topic they want to learn

TeachMate AI uses these preferences to generate a personalized learning experience.

### 2. AI-Generated Lessons
The application generates easy-to-understand lessons based on the selected topic and student's learning profile.

### 3. Study Material Upload
Students can upload study materials such as:
- PDF
- DOCX
- PPTX
- TXT

The uploaded material can be used as learning context.

### 4. RAG-Based Learning
TeachMate AI uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from uploaded study materials and use it while generating responses.

This helps the AI provide answers based on the student's learning material.

### 5. AI Teacher
Students can ask questions about the topic and receive explanations from the AI teacher.

### 6. Understanding Evaluation
The application can evaluate the student's understanding and provide adaptive feedback.

### 7. Quiz Generation
TeachMate AI generates a 5-question quiz to help students test their understanding.

### 8. AI Teacher Video
A HeyGen AI avatar video is used to demonstrate an AI teacher explaining educational content.



## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- HeyGen
- Retrieval-Augmented Generation (RAG)
- Python-dotenv
